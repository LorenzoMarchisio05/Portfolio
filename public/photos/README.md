Photographs for the SIX FRAMES section and the /gallery page.

Everything here is generated by scripts/photos.sh — never hand-edit these files
or point the script at them, or the © mark gets stamped twice. Clean originals
live in ../../photos-src/ (gitignored). After adding or changing one:

  scripts/photos.sh

Each output is capped at 2000px on the long side, gets "© LORENZO MARCHISIO"
burned into its bottom-right corner, keeps its Display P3 profile, drops EXIF
(so camera serial numbers and GPS coordinates do not ship) and carries copyright
XMP.

/gallery shows every .webp here from the next build on, loading the 800px copy
in thumbs/ in the grid. Name originals <number>-<category>[-more-words],
e.g. 042-croatia-plitvice: any number of digits, sorted numerically. The
category becomes a filter on the page (a two-word one takes an underscore:
08-street_food); the words are alt text only. photos-src/ entries may be
symlinks to the originals wherever they live. The grid picks a cell shape from
each photo's ratio and rearranges them to keep rows full.

Six Frames uses the slots below, each with one ratio at every width; CSS crops
to it with object-fit: cover, centred. Add object-position on a frame if a
centred crop cuts something.

  01-motorcycle   3:2
  02-croatia      2:3
  03-sport        3:2
  04-sport        2:3
  05-croatia      3:1 panorama — the deepest crop, keeps the middle band
  06-motorcycle   3:2

A slot file that is absent keeps the striped placeholder. A file that is present
needs `alt` filled in, in src/components/sections/Photography.astro.
